        01
        SKILLS
        技能
      
        
    
        A skill is a SKILL.md with a name and description in its front matter, followed by instructions.
      In agent mode the model sees every enabled skill's description and loads the full text when a task matches. In any mode, type / in the composer to attach a skill to your message.
      Import a .md file or a .zip of skill folders (Anthropic skill format).

        Tools from every ready server are offered to the model in agent mode.
      stdio servers run inside the RyuCore container (npx and uvx are installed); http is Streamable HTTP; sse is the older HTTP+SSE transport.
